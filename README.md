# Power electronics circuit simulations

Six reproducible MATLAB/Simulink simulations cover single-phase and three-phase controlled rectifiers, voltage-source and current-source inverters, the inverting buck-boost converter and the Cuk converter.

Run pe_run('smoke') for the six representative operating points, or pe_run for the full operating-point sweep. Each archive records the solver setup, time series, circuit diagrams, plots and runtime information.
